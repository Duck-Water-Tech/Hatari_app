🚀 HOW IT WORKS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. User Opens App
   └─ Gets location automatically (22.5726, 88.3639)

2. Calculate Distances
   └─ Measures to all 10 branches

3. Sort & Identify Nearest
   └─ Hatari Downtown: 2.3 km (NEAREST)

4. Show in Dropdown
   ├─ ✓ Hatari Downtown (2.3 km) - GREEN & SELECTABLE
   ├─ 🚫 Hatari North (3.8 km) - GRAY & DISABLED
   ├─ 🚫 Hatari South (4.2 km) - GRAY & DISABLED
   └─ 🚫 ... (8 more disabled)

5. User Can:
   ├─ TAP Nearest → Select it
   ├─ TAP Change Location → Open Google Maps
   └─ Pick new location → Dropdown updates
